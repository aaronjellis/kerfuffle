# Book Box Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a laser-cut **Book box** template: one wrap piece (back cover, living-hinge spine, front cover) around a four-wall page block, with guide pins, page lines, patterns, and artwork.

**Architecture:** A new engine module, `src/engine/bookBox.ts`, owns the layout math and generates the panels, the way `wineCarrier.ts` does for the wine carrier. On the sheet the wrap is one 2D panel with three sub-faces; in 3D it is three panels (`bottom`, a bent `left` spine, `top`) so each face takes its own artwork decal, and the front cover's pose is computed from the spine's bend. A new **Book** inspector section holds the book's own settings.

**Tech Stack:** TypeScript, React 18, three.js, Vitest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-11-book-box-design.md`

## Global Constraints

- Template id `'finger-book'`, category `'wood-finger'`. Box type id `finger-book`, name **Book box**, blurb "A cover that opens on a curved spine".
- Face ids: `top` front cover, `bottom` back cover, `left` spine, `right` fore edge, `front` tail, `back` head, plus `spine-wall`. Default names: **Front cover**, **Back cover**, **Spine**, **Fore edge**, **Tail**, **Head**, **Spine wall**.
- New parameters and defaults: `bookCoverOverhangMm: 4`, `bookSpineRadiusMm: 0` (0 = full round), `bookGuidePins: true`, `bookPageLines: true`, `bookPageLineSpacingMm: 1.5`.
- Overhang range max(3 mm, T) to 10 mm. Page line spacing range 0.8 to 5 mm. Solid band max(5 mm, 1.5T). Cover corner radius 2 mm. Pin length max(6 mm, 2T), height T. Spine face is the flat band when the band is at least 10 mm, the whole strip otherwise.
- Hinge cuts use the existing `livingHinge*` settings through `livingHingeZoneCuts`; they cover the two arcs only.
- Don't change the output of any other template. The existing test suite stays green, snapshots untouched.
- UI copy follows the Google developer style: sentence case, no exclamation marks.
- Names, controls, and defaults are Kerfuffle's own; don't copy another tool's book box.
- Commit only if the owner has asked for commits; otherwise leave each task's changes uncommitted and skip its commit step.

## Review Focus

- **Thin book.** Inner height 15 mm with 3 mm wood and the default hinge pattern: the box still generates, and the inspector warns that the spine is tighter than the pattern bends. (Tasks 1, 6)
- **Thick wood.** T = 6 mm: the overhang rises to 6 mm, and no wall slot or pin slot comes within 2 mm of a cover edge. (Task 2)
- **Outside sizing.** `dimensionReference: 'outer'`: the reported outer size equals the typed size within 0.01 mm. (Task 3)
- **Short walls with pins.** Inner depth 15 mm: two pins don't fit on the fore-edge wall; it gets one centred pin, or none, never overlapping pins or a pin on a finger joint. (Task 2)
- **Old project files.** A project saved before this change loads with the five book defaults; a `finger-book` project round-trips. (Task 3)

### Task 2: The pieces on the sheet

**Files:**

- Produces:

```ts
export function generateBookBox(params: BoxParameters, innerW: number, innerD: number, innerH: number):
  { panels2D: BoxPanel2D[]; panels3D: Panel3DTransform[]; fingerCountSummary: string; outerDims: BoxDims };
```

  This task fills `panels2D` and leaves `panels3D` empty. Panel ids: `wrap`, `front`, `back`, `right`, `spine-wall`.

**The wrap panel's frame** (y down): x runs 0 at the head to `wrapWidthMm` at the tail. From the top: front cover (`0 … coverLength`, fore edge at y = 0), spine strip, back cover (fore edge at the bottom). Sub-faces: `top` and `bottom` are the whole cover rectangles; `left` is the flat band when `flatBandMm >= 10`, else the whole spine strip. `safeRect` is the front cover inset to the page block's interior footprint.

**Wall panels.** Each is `innerH` tall between the covers. `front` and `back` span `innerW + 2T` and own the corners; `right` and `spine-wall` span `innerD`. Vertical edges are finger joints with `computeOddFingerCount(innerH, fingerWidthMm)`; top edges are plain; bottom edges carry tabs `T` deep (`tabbedEdge`, runs inset 6 mm from each end, `tabCountFor`, `TAB_MM`, as the wine carrier's floor). The matching slots (`slotsFor`) are cut paths in the wrap's back cover.

**Guide pins.** With `bookGuidePins`, the `right` wall's top edge has pins `T` tall, `pin = max(6, 2T)` long, centred at ¼ and ¾ of `innerD`, top corners chamfered `min(1, T/3)`. If `innerD < 4·pin`, use one pin at the centre; if `innerD < 2·pin`, none. The front cover gets one slot per pin, `pin − kerf` by `T − kerf`.

**Page lines.** With `bookPageLines`, and no see-through pattern set for that face in `params.facePatterns`, walls `front`, `back`, `right` get open score paths (`layer: 'score'`, ids `<wall>-page-<n>`) across the wall's full width, spaced `clamp(bookPageLineSpacingMm, 0.8, 5)`, starting one spacing below the top edge and ending at least one spacing above the bottom edge.

**Hinge cuts.** Two zones on the wrap, one per arc, each `wrapWidthMm` wide and `arcLengthMm` long, from `livingHingeZoneCuts`, as cut paths with ids `wrap-hinge-<n>` (`closed: false`).

- Consumes: `bentPoint`, `partlyBent` from `bentPanel.ts`.
- Produces:

```ts
/** The front cover's position and orientation with the spine `share` of the way bent (0 flat, 1 closed). */
export function bookCoverPose(model: GeneratedBoxModel, share: number): { position: [number, number, number]; quaternion: [number, number, number, number] };
/** Pattern targets for the covers: the page block's interior footprint on each. */
export function bookPatternTargets(panels2D: BoxPanel2D[], panels3D: Panel3DTransform[], params: BoxParameters): PatternFaceTarget[];
```

  `panels3D` ids and `faceId`s: `bottom`, `left`, `top`, `front`, `back`, `right`, `spine-wall`.

**3D frames.** World: x spine to fore edge, y up, z head (−) to tail (+), outer box centred on the origin. Each wrap panel's outline frame is its sub-rectangle of the wrap (`left` is always the whole spine strip in 3D), so sheet-x maps to world +z on all three.
- `bottom`: flat, outer face down (local +z → world −y), local up → world −x.
- `left`: `bend: { segments: layout.spineSegments, lines: <the hinge cuts in its frame> }`, foot on the back cover's bend line, heading world −x, bending toward world +y. `explodedPos` equals `closedPos`.
- `top`: flat, outer face up, local up → world +x. `closedPos` equals `bookCoverPose(model, 1).position`.
- Walls: `closedPos` from `innerX0`/`innerX1` and ±`innerD/2`; `explodedPos` 1.6× out in x and z as the wine carrier does; `outlinePoints` and `holeContours` from Task 2; `surfaceLines` carry the page lines; `patternSafe: true`.
- Colours: wrap pieces `'#dfc195'`, walls `'#cda676'`.

**`bookCoverPose`.** With `segs = partlyBent(layout.spineSegments, share)`, the spine's end and heading come from `bentPoint(segs, spineLengthMm, 0)` and the summed arc angles; the cover continues straight from that end for `coverLengthMm / 2`. At share 1 it lies on the page block; at 0 it lies in the back cover's plane on the far side of the spine, outer face down.

**Assembly.** In `applyAssemblyTransform`, for `templateId === 'finger-book'` and `spec.id === 'top'`, set the wrapper from `bookCoverPose(model, t·t·(3 − 2t))` and skip the generic branches. The spine already rebends through the existing `spec.bend` loop.

**Patterns.** In `resolvePatternFaces`, for `finger-book`, take `top` and `bottom` from `bookPatternTargets` and let `front`, `back`, `right` go through the existing direct-panel path. `left` and `spine-wall` are never targets.
